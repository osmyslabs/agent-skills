# Contributing

This is an experimental collection maintained by Osmys Labs. Open an issue or
pull request with the concrete task, observed behavior and expected outcome.
Use synthetic examples; omit private repositories, local user paths, credentials
and customer data. For vulnerabilities, follow [SECURITY.md](SECURITY.md).

Keep changes proportional. Preserve existing project conventions and user
authority, avoid generic checklist growth, and put conditional detail in relevant
references rather than expanding the entry point for every past failure.

For instruction changes, explain which decision or behavior changes and why.
For host compatibility claims, identify the client/version, installation scope
and actual commands or task evidence. A path-copy test is not a native agent run.
Report unavailable or inconclusive checks as such.

Run the validation commands in [README.md](README.md). Add meaningful tests for
changed helper behavior and keep the corpus's raw requests separate from grading
criteria. Retain failed evaluation outcomes when comparing revisions. Contributions
are provided under the repository's [MIT license](LICENSE).

No new runtime service, cloud resource or account is needed to contribute. Review
and support are best effort; maintainers may narrow or decline changes that expand
the skill beyond its stated purpose.
