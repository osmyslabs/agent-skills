# Changelog

## 0.1.0 — 2026-10-28

Initial experimental public distribution under the MIT license.

- Portable architecture workflow with conditional references for decisions,
  domain boundaries, security, safe evolution and infrastructure lifecycle.
- Optional Codex metadata and a standard-library installer for Codex, Claude Code
  and GitHub Copilot project/personal folders.
- Eight synthetic task fixtures, 12 offline helper tests and a Linux/Windows CI
  matrix. Native host and behavioral limitations are recorded explicitly.

The skill is experimental. Native Claude Code and Copilot execution and live
production outcomes are not certified by the package checks.
